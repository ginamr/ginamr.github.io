At UCI I took Projects in Databases and Web Applications. I worked with two other students for ten weeks on a full-stack movie e-commerce website. The site enabled users to purchase and search for movies. As the DBA, I took responsibility for parsing the XML movie data and maintaining information about each movie and creating end points for my team's JavaScript to easily interact with the database.

My Database Tables

  • Credit Cards
  • Customers
  • Employees
  • Genres
  • Genres in Movies
  • Movies
  • Sales
  • Stars in Movies

My Table Indicies

  • Credit Cards: primary key only
  • Customers: cc_id (credit card id)
  • Employees: primary key only
  • Genres: primary key only
  • Genres in Movies: movie_id
  • Movies: title
  • Sales: customer_id and movie_id
  • Stars in Movies: movie_id

My Stored Procedures

  • doesStarsExist - checks if a given star is in the movie database(DB)
  • getXStars - selects the top given number of stars from the DB
  • insertG - inserts a genre into the movie DB
  • insertM - inserts a movie into the movie DB
  • insertPairStarMovie - inserts a given movie and actor into the database together
  • search - queries DB for a movie given any of its attributes
  • searchByDirector - queries DB for a movie given a director name
  • searchByStarName - queries DB for a movie given a movie star name (given first name, last name, or both)
  • searchByTitle - queries DB for a movie given a title (given part of the title or the entire title)
  • searchByYear - queries DB for a movie given a year
  • verifyCustomer - verifies user login credentials for login page
